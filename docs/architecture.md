# 系统架构

## 目标

平台输出的是“证据链 + 风险分级 + 合规建议”，不是真假判决。所有结论必须能回溯到信号值、质量条件和模型版本。

## 请求链路

```text
Next.js
  -> POST /v1/jobs
  -> PostgreSQL 建任务
  -> Redis / Celery 或进程内后台任务
  -> DetectionPipeline
     -> L0 溯源与元数据
        -> L0 渲染链路指纹（Remotion + Lavf，弱阳性）
     -> L1 人脸检测与质量门控
     -> L2 视觉伪影
     -> L2.5 数字人专属特征（眨眼/眼周、头部微动、手部缺失）
     -> L3 时序一致性
     -> L5 唇音同步与音频反欺骗（启发式或 ONNX 模型）
     -> L7 分层融合、温度缩放、分位数阈值、三级判定
  -> 报告 JSON / HTML / 热力图
  -> GET /v1/jobs/{id}/report
```

## 质量门控

质量门控独立于检测模型：

- 人脸检出比例。
- 人脸面积占画面比例。
- 拉普拉斯清晰度。
- 曝光。
- 正面姿态近似。
- 可见肤色比例近似。

低于阈值时直接返回“无法确定”，不会把低质量样本硬塞进视觉分支。边缘质量样本即使分数越过疑似阈值，也会降级为灰区。

## 信号融合

当前融合器读取 `configs/fusion.json`：

1. 排除不可用信号。
2. 美颜/滤镜分数高时，把视觉伪影分数拉向 0.5（中性），而不是拉向“真实”。
3. 层内按信号权重加权平均：溯源层、帧内视觉层、数字人特征层、时序层、音视频一致性层、音频层。
4. 层间按 `layers` 权重合并，避免同层相关信号重复计权；`processing.layer_scores` 输出各层分数。
5. 温度缩放校准到 [0, 1]，偏移项固定为 0。
6. 信号差异过大时标记冲突并降级。
7. 溯源阳性按合规硬规则直接判“疑似生成合成”；渲染链路指纹只作为弱阳性参与融合。

灰区阈值由 validation split 的校准分数分位数确定（`dhfp calibrate`，默认 25% / 75%），
测试集只用于最终指标，不参与温度拟合或阈值选择。评测集或生成器分布变化后必须重新校准。

生产版本应将启发式权重替换为 LightGBM stacking 或贝叶斯似然比模型，并按业务场景选择操作点。

## 存储边界

- PostgreSQL：任务、报告、申诉和审计日志。
- MinIO / S3：原始媒体和派生产物。
- 本地开发：SQLite + 本地文件系统 + 进程内任务。
- FastAPI 主进程不加载 PyTorch；视觉模型只通过 ONNX Runtime 或外部命令适配器运行。

## 审计

以下动作写入 `audit_logs`：

- 提交任务。
- 查看报告。
- 提交申诉。

部署时应把审计日志写入不可变存储或独立归档，保留至少 6 个月。

## 阶段 2 进展

已实现：

- 灰区触发：复核仅在融合分数 `[gray_zone_min, gray_zone_max]`（默认 `[0.30, 0.70]`）运行，质量门控失败时直接跳过。
- 音频反欺骗：可配置 ONNX 模型（AASIST / WavLM 等）；显式配置后模型缺失或推理失败返回“不可用”，不静默回退到启发式。
- 数字人专属证据层：眨眼/眼周动态、头部微动频谱、手部缺失，作为弱阳性参与分层融合。
- 评测集工程：ChatCut 变体索引构建（`scripts/build_chatcut_dataset.py`）与同强度重编码增广（`dhfp augment-reencode`），保证所有标签使用相同编码参数。
- `EvidenceReviewProvider` 协议：外部 L6 MLLM 可通过该协议接入，不修改检测流水线。
- OpenAI-compatible HTTP provider：调用独立 Chat Completions 服务，只发送证据 ID、方向和分数，不发送媒体或原始人脸。
- 证据约束 verifier：陈述必须引用现有证据 ID，且陈述类型必须与证据方向一致；不合规陈述整条拒绝。
- 默认规则提供器：没有外部模型时只生成可回溯的证据摘要，不新增事实或身份判断。
- 定位评测：数据集支持可选时间片段和带时间戳的空间框标注，runner 输出 IoU、AP@IoU、Precision、Recall 和片段级校准误差。
- 红队扰动：生成并实际执行 FFmpeg 变换，输出媒体与 JSON manifest；噪声扰动明确标记为代理攻击。
- 持续学习：按标签和生成器分层抽取回放样本，并在评测报告之间执行发布回归门禁。

外部依赖，不属于当前仓库可独立完成项：

- 外部 provider 的真实服务凭据和模型权重。
- 授权评测数据录入与校准拟合。
- 梯度对抗攻击适配器；当前只提供噪声代理攻击。
